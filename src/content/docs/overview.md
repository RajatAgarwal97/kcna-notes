The **Kubernetes and Cloud Native Associate (KCNA)** is an entry-level, multiple-choice
certification from the CNCF. It tests foundational knowledge of Kubernetes and the
wider cloud native ecosystem.

## Exam domains and weighting

| Domain | Weight |
| --- | --- |
| Kubernetes Fundamentals | 46% |
| Container Orchestration | 22% |
| Cloud Native Architecture | 16% |
| Cloud Native Observability | 8% |
| Cloud Native Application Delivery | 8% |

## How these notes are organized

Each domain has its own page in the sidebar. Within a page I keep short, scannable
summaries in my own words, with links to the official docs where I want more depth.

:::caution
Always double-check weightings and objectives against the official
[KCNA curriculum](https://github.com/cncf/curriculum), since they change over time.
:::
